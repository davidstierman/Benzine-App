# Brandstof-app

Een mobiele GitHub Pages-webapp voor tankbeurten en brandstofverbruik.

## Publiceren op GitHub Pages

1. Maak op GitHub een nieuwe repository, bijvoorbeeld `brandstof-app`.
2. Upload alle bestanden en de map `icons` uit dit pakket naar de hoofdmap van de repository.
3. Open in de repository: **Settings > Pages**.
4. Kies bij **Source**: **Deploy from a branch**.
5. Kies branch **main** en map **/(root)** en klik **Save**.
6. Open na publicatie het adres dat GitHub bij Pages toont.

## Installeren op iPhone

Open de gepubliceerde site in Safari, tik op de deelknop en kies **Zet op beginscherm**.

## Gegevens en backup

Tankbeurten worden lokaal in de browser opgeslagen. Gebruik daarom regelmatig **Backup > Backup downloaden (JSON)**. Bij het wissen van Safari-websitegegevens kunnen lokale tankbeurten verloren gaan.
